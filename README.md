> ### PetroTwin — *Flagship*
> **Enterprise Digital Twin platform for marginal oil field operations.**
>
> A deterministic, physics-based simulation platform built around a secure industrial architecture (**OT → SCADA → DMZ → IT → AI**). It streams real-time telemetry through Redis and Socket.IO, persists high-frequency time-series data in TimescaleDB, and includes an **ISA-18.2 compliant alarm engine** on a high-performance backend.
